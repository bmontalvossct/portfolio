# Icon sources and licenses

The SVGs in this directory use filenames prefixed by their icon collection. Assets were retrieved from Iconify's SVG API, except `lucide--database.svg` (Lucide's source repository) and the Simple Icons files listed below that were retrieved from simpleicons.org after the Iconify API returned errors.

- `logos--*`: [SVG Logos by Gil Barbara](https://icon-sets.iconify.design/logos/), CC0.
- `simple-icons--*`: [Simple Icons](https://simpleicons.org/), CC0 1.0. `credly`, `googlebigquery`, `inertia`, `mikrotik`, `n8n`, `sap`, and `scikitlearn` were retrieved from simpleicons.org; the remaining icons were retrieved through Iconify.
- `cib--*`: [CoreUI Brands by creativeLabs](https://icon-sets.iconify.design/cib/), CC0 1.0.
- `devicon--*`: [Devicon](https://github.com/devicons/devicon), MIT; see LICENSE-devicon.txt.
- `lucide--*`: [Lucide](https://github.com/lucide-icons/lucide), ISC; see LICENSE-lucide.txt.
- `mdi--*`: [Material Design Icons by Pictogrammers](https://github.com/Templarian/MaterialDesign), Apache 2.0 for icons; see LICENSE-mdi.txt and https://www.apache.org/licenses/LICENSE-2.0.
